# Fan-out and fan-in cones; cut-off on the hot/cold colours

Date 2026-10-28. Branch `feat/cones`. Purpose: hub RQ W Q3.3; measure: speed (the logic around the
critical and near-critical paths). Reads Mímir schema 7 (`hdl_edge`, `hdl_port`; Mímir
`docs/specs/2026-10-28-hdl-graph.md`) and schema 6 (`timing_path_node`).

## Buttons

`>` (fan-out: forward to the primary outputs) and `<` (fan-in: back to the primary inputs), in the
source view toolbar and in the Paths panel. They act on the token last clicked in the source view.

## Two cones, always labelled

- **Structural cone** (default; needs schema 7). Breadth-first walk of the stored line-level graph,
  starting at the nodes of the clicked token (its line, then its word, then its bit when they match).
  Level = distance in logic levels. Registers stop the walk by default (forward: the edge that
  leaves a register output is not taken; backward: the register is reached, named "register", and
  the walk ends); the box "cross registers" continues to the true primary inputs or outputs. PIs
  and POs are named.
- **Timing cone** (also the fallback when the store has no graph, with a note). On every stored path
  through the token, the steps after (>) or before (<) it; level = steps from the token; limited to
  the reported paths and stops at the end of the paths (registers). Says so in the panel.

The Paths panel lists the cone's lines grouped by level (file:line, word[bit], module, end kind,
crit); clicking one scrolls the source view (a line in another file opens that file). The source
view shows the level of each cone line in the gutter (L0, L1, ...); the heat colours stay and every
other line is dimmed. Choosing a path or Clear cone removes the cone.

## Near-critical cut-off (Peter 2026-10-28)

One setting (0.90 default, 0.95, 0.99, off; the Paths panel). A cone line whose crit
(`timing_object` span `crit_max`; none = unknown) is below it is not listed, numbered or coloured
(counted: "N line(s) below crit 0.90 are not shown"). The base hot/cold colouring obeys the same
cut-off: a token or line below it is plain text. The data stays in the store.
