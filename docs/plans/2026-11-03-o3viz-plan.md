# o3viz implementation plan (2026-11-03)

Spec: `docs/specs/2026-11-03-o3viz-design.md`. Each task ends green (ruff, mypy --strict, unittest) and is committed.

## M1 "just want to see"
1. `wyrd/o3viz/blif.py`: parse a BLIF (names, latch, subckt) to edges, fanin/fanout, logic level. Test on a tiny BLIF.
2. `wyrd/o3viz/vprfiles.py`: parse `.place`, `.net` (clusters and contained atoms), setup timing report (slack per atom). Tests on tiny files.
3. `wyrd/o3viz/steps.py`: read `prov/index.json` and the step object files. Test on the fixture.
4. `wyrd/o3viz/anchors.py`: `placement` anchor (grid at the bottom, centroids upward). Test: bottom equals VPR xy, all linked objects placed.
5. `wyrd/o3viz/export.py`: assemble planes (hdl, lut, clb, placed), links, edges, metrics, manifest, copy HDL; deterministic writer. Tests: schema, determinism.
6. `wyrd/o3viz/serve.py` and CLI `wyrd viz export|serve`. Test: argument parsing, serve a bundle and fetch the manifest.
7. Viewer `wyrd/o3viz/web/`: three.js plane stack, colour dropdown, click core sample, auto-rotate. Vendor three.
8. Run on VTR `ch_intrinsics` through `odin3-flow --prov`; screenshot; PR.
